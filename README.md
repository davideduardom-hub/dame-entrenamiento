# Dame entrenamiento

Aplicacion web de entrenamiento y nutricion que funciona sin cuenta, sin publicidad y sin conexion.
Todos los datos se guardan unicamente en el navegador de quien la usa: no hay servidor ni base de datos.

## Como publicarla

Sube estos archivos a la raiz del repositorio y activa GitHub Pages en Settings > Pages.

## Aviso

No sustituye el criterio de un medico. Consulta a un profesional antes de iniciar un deficit calorico o un plan de ejercicio.
